# Submission

Submit a private repository or private archive containing:

```text
candidate-solution/
├── README.md
├── REPORT.md
├── requirements.txt / environment file / build instructions
├── src/
├── config/
├── output/
│   ├── annotated video or visual result
│   ├── events.jsonl or events.json
│   ├── counts.csv
│   └── evidence snapshots
└── tests/ (recommended)
```

## README must include

- operating system tested;
- language/runtime versions;
- exact setup commands;
- exact run command;
- expected input format;
- output locations;
- hardware used;
- known limitations.

## REPORT.md must include

- problem selected;
- architecture/approach;
- detector/model/tracker used;
- why those choices were made;
- accuracy/evaluation method and measured results;
- runtime performance (FPS or processing time);
- major failure cases;
- what you would improve with more time;
- AI development tools used;
- third-party components/models and licenses.

## Important

Do not publish your final solution into this public starter repository. Share the completed work privately with the TSCI interview team.
