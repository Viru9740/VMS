# Example Event Types

Candidates may extend this list.

- `A_TO_B`
- `B_TO_A`
- `LINE_CROSSING`
- `ZONE_ENTRY`
- `ZONE_EXIT`
- `DWELL_THRESHOLD`
- `OCCUPANCY_THRESHOLD`
- `QUEUE_THRESHOLD`
- `RESTRICTED_ZONE`
- `CUSTOM_EVENT`

Events should be derived from tracked observations and should retain enough information to trace the event to visual evidence.
