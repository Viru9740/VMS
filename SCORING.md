# Scoring Rubric — 100 Points

| Area | Points |
|---|---:|
| Working end-to-end system | 20 |
| Detection/tracking/event accuracy | 15 |
| Hidden-video generalisation | 15 |
| Engineering architecture | 10 |
| Evidence output / data quality | 10 |
| Original useful extension | 10 |
| Performance/resource handling | 5 |
| Code quality | 5 |
| Reproducibility/documentation | 5 |
| Live explanation/debug/modification | 5 |

## Evaluation notes

A polished UI does not compensate for incorrect counts, unstable tracking or irreproducible results.

Candidates should measure rather than merely claim accuracy. Strong submissions explain false positives, false negatives, ID switches, duplicate suppression and known scene limitations.

The final live review may include unseen video and a small modification request.
